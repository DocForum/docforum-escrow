Issue #325 (Phase E6): added `EscrowClient.transferPayee({ escrowId, currentPayee, newPayee })` to the SDK, wrapping the contract's `transfer_payee`. It accepts a `Keypair` or SEP-43 signer for the current payee, pre-checks client-side that the escrow is `Funded` and that `newPayee` is neither the payer nor the contract id (`EscrowPreconditionError` with code `InvalidNewPayee`, matching contract error 37), and is carried by `prepareLifecycleCall` as method `transfer_payee`. Offline tests added in `sdk/tests/lifecycle.test.ts`. No contract change, so the generated bindings are unchanged.
