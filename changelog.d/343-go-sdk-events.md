Issue #343 (Phase E6): added `GetEvents` to the Go SDK. It pages the RPC `getEvents` endpoint for the escrow contract and decodes lifecycle event snapshots into typed `Event`/`Escrow` values, supporting both the 12-field and 13-field (with fee) layouts. Unknown event shapes are reported as `Unknown` so a page is never failed by a newer shape. Includes decoder tests and a mocked-RPC paging test.
