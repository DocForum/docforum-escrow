Issue #330: Added `EscrowClient.getEscrows(ids)` in `@docforum/escrow-sdk` to batch-read persistent `DataKey::Escrow(id)` ledger entries via `getLedgerEntries` (chunked to 200 keys per RPC call), decode them with `decodeEscrowDataFromScVal`, and return `Map<bigint, Escrow | undefined>` (throwing `ArchivedEntryError` on expired TTLs). Offline unit tests in `sdk/tests/escrow-data.test.ts` pin the `DataKey::Escrow(id)` encoding and cover batching, missing entries, and archived entries.
