Issue #328: Added opt-in `mode: "onchain"` to `BatchOptions` in `@docforum/escrow-sdk` so `createEscrows` and `settleMany` submit chunks via the contract's `create_escrows` (max 16) and `settle_many` (max `MAX_SETTLE_OPS = 12`) entry points, grouping by signer/caller, falling back to `createEscrow` for items with fees/callbacks/custom `refundTo`/multi-releaser, and mapping per-op results back to input order. Offline tests in `sdk/tests/batch.test.ts` cover chunking, caller grouping, atomic/callback failures, and `resumeFrom`.
