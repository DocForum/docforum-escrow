Issue #365 (Phase E6): added `examples/payee-callback/`, an example contract payee implementing the `on_escrow_released(escrow_id, amount)` release callback from ADR 0005. It records payouts, rejects unknown escrows, and supports a reject mode to simulate a failing hook. Tests cover the happy-path callback, the net-of-fee payout, a failing hook reverting the release (refund still works), and rejection of unknown escrows. CI builds and tests the crate.
