Issue #358 (Phase E6): added a TypeScript `ReleaserAccountClient` for the releaser custom account contract. It computes the management digest byte-for-byte with `ReleaserAccount::management_digest`, signs management payloads, builds `Vec<SignerSignature>` settle credentials, and can execute `manage`. Includes `sdk/js-xdr.d.ts`-free runtime XDR serialization and offline tests verified against a shared Rust test vector. No contract change, so no generated bindings are required from this PR (the releaser-account bindings still need the pinned Stellar CLI to generate and drift-check).
